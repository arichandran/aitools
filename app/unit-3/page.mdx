### <a id="_Toc239677983"></a>3\.1 AI\-Assisted Spreadsheet and Dataset Analysis Using Natural Language

Traditionally, analysing a dataset required knowing spreadsheet formulas \(VLOOKUP, PIVOT TABLE\) or a programming language \(Python/pandas, R\)\. AI\-assisted data\-analysis tools \(ChatGPT's Advanced Data Analysis / Code Interpreter, Microsoft Copilot in Excel, Julius AI\) remove this barrier: a user uploads a file \(\.csv, \.xlsx\) and asks questions in plain English, such as 'What is the average marks per section?' The tool internally writes and runs code \(typically Python\) to compute the answer, then explains the result in natural language — combining the rigor of programmatic computation with the accessibility of conversational interaction\.

### <a id="_Toc239677984"></a>3\.2 Natural\-Language Querying of Datasets

A natural\-language query is a plain\-English question about the data rather than a formula\. Effective queries are specific about the column names, the aggregation required \(sum, average, count, maximum\), and any filter conditions\. Compare a vague query \('tell me about this data'\) with a precise one \('What is the average attendance percentage for students in Section B, and how many students in that section have attendance below 75%?'\) — the precise query yields a directly usable, checkable answer\.

### <a id="_Toc239677985"></a>3\.3 AI Tools for Generating Charts and Visual Summaries

Once a dataset is uploaded, most AI data\-analysis tools can generate a chart on request — e\.g\., 'plot a bar chart of average marks by subject' or 'show a pie chart of pass vs fail counts'\. Choosing the right chart type matters for correct interpretation:

__Chart Type__

__Best Used For__

__Avoid When__

Bar chart

Comparing a numeric value across discrete categories \(e\.g\., average marks per subject\)

Showing change over continuous time \(use a line chart instead\)

Line chart

Showing a trend over an ordered sequence, typically time \(e\.g\., attendance over weeks\)

Comparing unrelated categories with no natural order

Pie chart

Showing proportion of a whole, with very few categories \(2\-5\)

More than 5\-6 categories, or when precise comparison between two similar\-sized slices matters \(bar chart reads more accurately\)

Scatter plot

Showing the relationship/correlation between two numeric variables \(e\.g\., study hours vs marks\)

Categorical data with no continuous numeric pairing

### <a id="_Toc239677986"></a>3\.4 Interpreting AI\-Generated Statistical Summaries Correctly

An AI tool can compute mean, median, mode, standard deviation, and correlation instantly, but interpreting what these numbers mean is the student's responsibility\. Some recurring pitfalls:

- __Mean vs median — __a single very high or very low value \(an outlier\) can pull the mean away from what is 'typical'; the median is more robust to outliers\. An AI summary that reports only the mean can be misleading for skewed data \(e\.g\., salary data with one extremely high earner\)\.
- __Correlation vs causation — __an AI noting that two variables are correlated \(e\.g\., ice\-cream sales and drowning incidents both rise in summer\) does not mean one causes the other; a third factor \(hot weather\) may explain both\.
- __Sample size — __a statistic computed from very few rows \(e\.g\., 5 students\) is far less reliable than one from hundreds of rows, even if the AI reports both with the same confident tone\.

### <a id="_Toc239677987"></a>3\.5 Identifying and Correcting Errors in AI\-Generated Data Analysis

AI data\-analysis tools make a specific, well\-documented category of mistake: misinterpreting a column's data type\. For example, a 'Roll Number' or 'Pincode' column contains digits but is categorical/identifier data, not something that should be averaged or summed\. Similarly, a date column stored as text \(e\.g\., '01\-02\-2026'\) may be misread as day\-first or month\-first depending on locale assumptions\. Detecting and correcting such errors requires the student to inspect a few raw rows of the actual dataset and sanity\-check any AI\-reported statistic against them\.

__Rule of thumb:__

Never accept a statistic on a column without first confirming what that column represents\. If an AI tool reports the 'average' of a Roll Number column, that is an immediate red flag that it has treated an identifier as a quantity\.

Cleaning instructions to give the AI tool, and the reasoning behind each:

### <a id="_Toc239677993"></a>Experiment 5: Cross\-Check One AI\-Generated Statistical Claim Manually

Problem: Cross\-check one AI\-generated statistical claim manually and report any discrepancy found\.

__*Step\-by\-Step Solution*__

Suppose an AI tool, given the Section B attendance data \(70, 82, 60, 91, 74\), reports: "The average attendance in Section B is 76\.4%\."

Manual verification: Sum = 70\+82\+60\+91\+74 = 377\. Count = 5\. Mean = 377 ÷ 5 = 75\.4%\.

__Discrepancy found:__

The AI's claimed value \(76\.4%\) does not match the manually verified value \(75\.4%\) — a difference of exactly 1\.0 percentage point, consistent with a simple arithmetic slip \(e\.g\., mis\-summing one value\) rather than a conceptual error\.

__*Explanation of Approach*__

This exercise is deliberately designed to surface a discrepancy so students practice the full verification workflow: recompute independently using basic arithmetic, compare exactly, and report the size and likely cause of any mismatch, rather than assuming the AI's number is correct because it was stated confidently and formatted like a fact\.

__*Alternative Method*__

A student could cross\-check using a spreadsheet's built\-in AVERAGE\(\) function as a second independent tool, which would also return 75\.4%, corroborating the manual calculation and further confirming the AI's figure was in error\.
